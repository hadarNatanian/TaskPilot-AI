🧭 TaskPilot AI — אג׳נט חכם לתכנון משימות וניהול זמן
הופך רשימת משימות לתוכנית עבודה מעשית באמצעות בינה מלאכותית ותכנון ב־Python.
🎯 על הפרויקט
במקומות עבודה רבים נדרש עובד להתמודד עם כמה משימות במקביל, כאשר לכל משימה יש רמת דחיפות שונה, משך ביצוע משוער ומועד יעד. לפעמים משימה אחת תלויה בהשלמת משימה אחרת, ולפעמים פשוט אין מספיק שעות כדי להספיק הכול.
במצב כזה, לא מספיק להכין רשימת משימות. צריך להבין מה כדאי לבצע קודם, אילו משימות אפשר להספיק במסגרת הזמן הקיימת, ומה צריך לדחות או לתכנן מחדש.
TaskPilot AI הוא אג׳נט שפיתחתי כדי להתמודד עם האתגר הזה. הוא משלב ניתוח באמצעות OpenAI API עם מנגנון תכנון וחישובי זמן ב־Python. המערכת מסייעת להפוך רשימת משימות לתוכנית עבודה מסודרת, תוך הצגת ההחלטות והסיבות לכך שמשימות מסוימות לא שובצו.
💡 הבעיה ולמה בחרתי בה
ניהול זמן ותעדוף משימות הם אתגרים יומיומיים בסביבת העבודה. ככל שמספר המשימות גדל, קשה יותר לראות את התמונה המלאה, לזהות התנגשויות ולהחליט כיצד לנצל את הזמן בצורה יעילה.
בחרתי בבעיה הזאת משום שהיא מעשית ורלוונטית, ומאפשרת להדגים כיצד אג׳נט AI יכול לסייע בקבלת החלטות ולא רק לספק תשובות טקסטואליות.
המטרה היא לפתח כלי שלא רק מציע מה לעשות, אלא גם בוחן אם התוכנית אפשרית במסגרת הזמן, מתחשב בקשרים בין משימות ומסביר את התוצאות.
🏢 תרחיש שימוש: תכנון שבוע עבודה
נניח שאני עובד בצוות בחברה, ובתחילת השבוע מקבל כמה משימות שעליי להשלים עד סוף השבוע. בין המשימות יש הכנת מצגת לישיבת צוות, ניתוח נתונים, הכנת מסמך וסיום בדיקות לפרויקט.
לכל משימה יש מאפיינים שונים:
•	משך משוער — כמה זמן נדרש כדי להשלים אותה.
•	דחיפות — עד כמה חשוב לטפל בה בהקדם.
•	חשיבות — עד כמה היא משמעותית למטרות העבודה.
•	מועד יעד — עד מתי צריך להשלים אותה.
•	תלויות — האם צריך להשלים משימה אחרת לפני שאפשר להתקדם.
אני מזין את המשימות ואת מגבלות הזמן לאג׳נט. המערכת מנתחת את הנתונים, בוחנת אילו שילובי משימות מתאימים למגבלות שהוגדרו ומציגה תוכנית עבודה לצד הסברים.
כך אפשר להבין מה כדאי לבצע, אילו משימות לא נכנסו לתוכנית ומדוע, ומה עשוי לדרוש תכנון מחדש.
⚙️ איך האג׳נט עובד?
המערכת משלבת שני חלקים שמשלימים זה את זה:
•	ניתוח באמצעות AI: OpenAI API מסייע בניתוח נתוני המשימות ובהפקת סיכומים והסברים.
•	מנגנון תכנון ב־Python: בודק שילובי משימות בהתאם למגבלות הזמן ולתלויות, ומסייע לבחור תוכנית אפשרית.
ההפרדה הזאת חשובה: מודל ה־AI מסייע להבין את המשימות ולהסביר את התוצאות, ואילו חישובי הזמן ובדיקות ההיתכנות מתבצעים באמצעות קוד.
שלבי העבודה
1.	הזנת המשימות: מזינים משימות, משך משוער, דחיפות, חשיבות ומועדי יעד.
2.	הגדרת תלויות: מציינים אילו משימות תלויות בהשלמת משימות אחרות.
3.	ניתוח הנתונים: המערכת נעזרת ב־AI כדי לנתח את המשימות ולהפיק הסברים.
4.	בדיקת היתכנות: מנגנון התכנון ב־Python בוחן שילובי משימות בהתאם למגבלות הזמן ולתלויות.
5.	בניית תוכנית: המערכת מציגה את המשימות שנבחרו ואת תוכנית העבודה שהתקבלה.
6.	הסבר ההחלטות: מוצגות גם משימות שלא שובצו והסיבות לכך, וניתן לעיין בשלבי קבלת ההחלטות באמצעות Trace.
כאשר מספר המשימות אינו עולה על 18, המתכנן בודק שילובים אפשריים באמצעות תכנות דינמי. במספר גדול יותר של משימות, הוא עובר לשיטת תכנון מהירה המבוססת על סדרי עדיפויות.

🖥️ הדגמה: כך המערכת נראית בפועל
צילומי המסך הבאים מציגים את שלבי העבודה באפליקציה — מהזנת המשימות, דרך הצגת התוכנית, ועד להבנת ההחלטות ולמניעת טעויות בתלויות.
1. המסך הראשי — הזנת המשימות
במסך הראשי מזינים את המשימות ואת הנתונים הנדרשים לתכנון. זהו שלב הגדרת הבעיה: המערכת זקוקה למידע על המשימות ועל מסגרת הזמן כדי לבנות תוכנית רלוונטית.

2. תוכנית העבודה — מה כדאי לבצע?
לאחר ניתוח הנתונים ובדיקת מגבלות הזמן, המערכת מציגה את תוכנית העבודה שנבחרה. התוצאה מסייעת להבין כיצד ניתן לנצל את הזמן הזמין בהתאם לנתונים שהוזנו.

3. מרכז ההחלטות — למה התקבלה התוצאה הזאת?
תכנון טוב צריך להיות מובן ולא להסתכם ברשימת המלצות. מרכז ההחלטות מספק מידע שעוזר לעקוב אחר ההיגיון שמאחורי התכנון ולהבין את בחירות המערכת.

4. משימות שלא שובצו — מה לא נכנס לתוכנית ולמה?
כאשר הזמן מוגבל, לא תמיד אפשר לכלול את כל המשימות. במקום להציג רק את מה שנבחר, המערכת מציגה גם משימות שלא שובצו ואת הסיבות לכך. כך אפשר לזהות אילו משימות דורשות שינוי בתכנון או בחינה מחדש של סדרי העדיפויות.

5. הגנה על תלויות — מניעת פעולות לא תקינות
משימות עשויות להיות תלויות זו בזו. למשל, ייתכן שמשימה אחת לא תוכל להתבצע לפני השלמת משימה אחרת. המערכת כוללת מנגנון הגנה מפני מחיקת משימה שמשימות אחרות תלויות בה, כדי למנוע פגיעה בקשרים שהוגדרו בתוכנית.

⚙️ התקנה והרצה
דרישות מקדימות
•	Python בגרסה התואמת לתלויות שב־requirements.txt.
•	מפתח OpenAI API תקין.
1. שכפול המאגר
git clone https://github.com/hadarNatanian/TaskPilot-AI.git
cd TaskPilot-AI
2. יצירת סביבה וירטואלית
python -m venv .venv
ב־Windows יש להפעיל את הסביבה באמצעות:
.venv\Scripts\activate
3. התקנת התלויות
pip install -r requirements.txt
4. הגדרת מפתח API
לצורך הרצה מקומית, יש ליצור קובץ .env בתיקיית הפרויקט ולהוסיף:
OPENAI_API_KEY=your_api_key_here
יש להחליף את your_api_key_here במפתח האישי שלך.
לחלופין, אפשר להגדיר את המפתח בקובץ .streamlit/secrets.toml:
OPENAI_API_KEY = "your_api_key_here"
הקוד בודק תחילה את Streamlit secrets ולאחר מכן את משתני הסביבה.
5. הפעלת האפליקציה
streamlit run app.py
לאחר ההפעלה, Streamlit יציג כתובת מקומית לפתיחת האפליקציה בדפדפן.
