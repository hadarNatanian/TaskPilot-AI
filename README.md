🧭 TaskPilot AI
אג׳נט חכם לתכנון משימות וניהול זמן 
TaskPilot AI היא אפליקציית תכנון משימות המשלבת ניתוח באמצעות OpenAI API עם חישובי זמן ובדיקות היתכנות ב־Python. המערכת מנתחת משימות, מתחשבת בדחיפות, בחשיבות, במועדי יעד ובתלויות, ומציגה תוכנית עבודה לצד הסברים על ההחלטות שהתקבלו.
🎯 הבעיה והפתרון
בסביבת העבודה, עובד עשוי לקבל מספר רב של משימות שעליו להשלים בפרק זמן מוגבל. לכל משימה יש משך ביצוע משוער, רמת דחיפות, חשיבות ומועד יעד. לעיתים משימות מסוימות תלויות בהשלמת משימות אחרות, ולכן לא תמיד אפשר לבצע אותן בכל סדר שרוצים.
במצב כזה, קשה להבין מה כדאי לבצע קודם, אילו משימות אפשר להספיק במסגרת הזמן הקיימת ומה צריך לדחות או לתכנן מחדש.
בחרתי לפתח את TaskPilot AI כדי להתמודד עם הבעיה הזאת באמצעות אג׳נט AI שמסייע בתכנון ובקבלת החלטות. המערכת משלבת ניתוח באמצעות OpenAI API עם אלגוריתם תכנון ב־Python, כדי לבחון שילובי משימות בהתאם למגבלות הזמן ולתלויות, ולהציג גם את הסיבות לכך שמשימות מסוימות לא נכללו בתוכנית.
🏢 תרחיש שימוש: תכנון שבוע עבודה
נניח שאני עובד בחברה ומקבל בתחילת השבוע מספר משימות שעליי להשלים עד סוף השבוע. לדוגמה: הכנת מצגת לישיבת צוות, ניתוח נתונים, כתיבת מסמך וסיום בדיקות לפרויקט.
אני מזין לאג׳נט את המשימות ואת הנתונים הרלוונטיים לכל אחת:
•	משך משוער — כמה זמן נדרש להשלמת המשימה.
•	דחיפות — עד כמה חשוב לטפל במשימה בהקדם.
•	חשיבות — מה התרומה של המשימה למטרות העבודה.
•	מועד יעד — עד מתי יש להשלים את המשימה.
•	תלויות — אילו משימות צריך להשלים לפני שאפשר להתקדם.
לאחר הזנת הנתונים, המערכת מנתחת את המשימות ובודקת אילו שילובים מתאימים למסגרת הזמן שהוגדרה. בסיום, היא מציגה תוכנית עבודה, משימות שלא שובצו והסברים על ההחלטות שהתקבלו.
כך אפשר להבין לא רק מה כדאי לבצע, אלא גם מדוע נבחר סדר מסוים ומה דורש בחינה מחדש.
⚙️ איך האג׳נט עובד?
המערכת משלבת שני מרכיבים שמשלימים זה את זה:
•	ניתוח באמצעות AI: OpenAI API מסייע בניתוח נתוני המשימות ובהפקת סיכומים והסברים.
•	תכנון ב־Python: מנגנון התכנון בודק שילובי משימות בהתאם למגבלות הזמן ולתלויות, ומסייע לבחור תוכנית אפשרית.
ההפרדה בין שני המרכיבים חשובה: ה־AI מסייע בניתוח ובהסבר, ואילו חישובי הזמן ובדיקות ההיתכנות מתבצעים בקוד. כך המערכת יכולה להציג תוכנית לצד הסברים על התוצאה, ולא רק רשימת המלצות.
שלבי העבודה
1.	הזנת משימות: מזינים את המשימות, משך הביצוע המשוער, הדחיפות, החשיבות ומועדי היעד.
2.	הגדרת תלויות: מציינים אילו משימות תלויות בהשלמת משימות אחרות.
3.	ניתוח באמצעות AI: המערכת מנתחת את נתוני המשימות ומפיקה סיכומים והסברים.
4.	תכנון ובדיקת היתכנות: Python בודק שילובי משימות בהתאם למגבלות הזמן ולתלויות.
5.	הצגת התוכנית: המערכת מציגה את המשימות שנבחרו ואת תוכנית העבודה שהתקבלה.
6.	הסבר ההחלטות: המערכת מציגה משימות שלא שובצו ואת הסיבות לכך, ומאפשרת לעיין בשלבי קבלת ההחלטות באמצעות Trace.
עד 18 משימות, המתכנן בודק שילובים אפשריים באמצעות תכנות דינמי. עבור מספר גדול יותר של משימות, הוא משתמש בשיטת תכנון מהירה המבוססת על סדרי עדיפויות.
✨ היתרונות המרכזיים

היתרון המרכזי הוא השילוב בין ניתוח באמצעות AI לבין בדיקות תכנון המבוססות על קוד. המערכת לא רק מציגה המלצות, אלא גם בוחנת את שילובי המשימות בהתאם למגבלות שהוגדרו.

2. תוכנית העבודה שהתקבלה

משימות עשויות להיות תלויות זו בזו. המערכת כוללת מנגנון הגנה מפני מחיקת משימה שמשימות אחרות תלויות בה, כדי למנוע פגיעה בקשרים שהוגדרו בין המשימות.

⚙️ התקנה והרצה
דרישות מקדימות
•	Python בגרסה התואמת לתלויות שב־requirements.txt.
•	מפתח OpenAI API תקין.
1. שכפול המאגר
git clone https://github.com/hadarNatanian/TaskPilot-AI.git
cd TaskPilot-AI
2. יצירת סביבה וירטואלית
python -m venv .venv
ב־Windows:
.venv\Scripts\activate
3. התקנת התלויות
pip install -r requirements.txt
4. הגדרת מפתח API
לצורך הרצה מקומית, צור קובץ בשם .env בתיקיית הפרויקט והוסף:
OPENAI_API_KEY=your_api_key_here
החלף את your_api_key_here במפתח האישי שלך.
אפשרות נוספת היא ליצור את הקובץ .streamlit/secrets.toml ולהגדיר בו:
OPENAI_API_KEY = "your_api_key_here"
הקוד בודק תחילה את Streamlit secrets ולאחר מכן את משתני הסביבה.
5. הפעלת האפליקציה
streamlit run app.py
לאחר ההפעלה, Streamlit יציג כתובת מקומית לפתיחת האפליקציה בדפדפן.
